# Product brief

## Problem

Shop filters depend on product attributes. In a large catalogue, most products are missing at least some of them, so they are invisible to shoppers who filter. Filling them by hand is slow. Filling them with AI is fast, but a wrong value puts a product under the wrong filter, which is worse than no value.

## Users

- **Catalogue or merchandising teams** who own product data quality and decide what goes live.
- **Search and discovery product managers** who need filters to cover more products.
- **Hiring managers** reading this portfolio, who want to see how I evaluate an AI feature before shipping it.

## Goals

1. Measure how often AI-filled values are right, per attribute, against values we already trust.
2. Compare with the cheapest non-AI method on the same text.
3. Find a rule for which values can go live without a person.
4. Keep every answer traceable to a quote in the product text.

## Non-goals for 0.1.0

- Writing values back to a catalogue.
- A review screen for people (the data table holds the proposals).
- Attributes with free values, such as dimensions or brand.
- Images. Only text is used.

## Success measures

This is a portfolio piece, so there is no usage target. It succeeds if a catalogue team could use the findings to decide which attributes to auto-fill, and at what risk.
